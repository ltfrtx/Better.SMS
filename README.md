# Better.SMS v1.8.1

> 下載 Release 的 Source code (zip) 解壓後，選擇包含 `manifest.json` 的資料夾以載入擴充功能。此發行版本不包含具名學生預設。


沿用 Better.SMS 的藍灰介面，提供獨立功課與提醒、選科篩選及日期篩選。**時間分析仍標示為測試版**。

## 1.8.1：放大彈出視窗

- 按工具列插件圖示，仍開啟原有的 Chrome 彈出視窗；預設大小為 **800 × 600 CSS 像素**，達 Chrome action popup 的標示上限。螢幕空間或縮放可能限制實際顯示。
- 寬版把功課卡片排列為兩欄，日期按鈕並排；時間分析的摘要與圓環圖分欄，圓環保持正圓。窄視窗自動回復單欄，不會整體拉伸。
- 設定中的「上下分區」仍把功課及提醒分開上下顯示；每個區塊的卡片在寬版內可分兩欄。
- 功課、提醒、日期篩選、Math 和 X 組選科、設定及同步方式與 1.8.0 相同；沒有改為獨立視窗或瀏覽器分頁。
- 如果只想與舊版比較，可在另一個資料夾載入本版作獨立插件；Chrome 會把它視為另一個插件，不會自動共用舊版的選科、勾選或快取，需重新設定。

## 安裝與更新

1. 解壓 `BetterSMS_1.8.1.zip`，在 Chrome 開啟 `chrome://extensions`。
2. 開啟「開發人員模式」，選擇「載入未封裝項目」，選擇解壓後、內含 `manifest.json` 的 **BetterSMS** 資料夾。
3. 登入 [SMS 功課頁](https://sms.twghlkss.edu.hk/student/records.php?feature=homework)，安裝後重新載入該頁。點擊插件圖示，在「學生設定」選擇 Math Group、X1、X2、X3。
4. 在主畫面按 **時間分析 β**；右下角 **⚙ 設定**可選擇「頁籤模式」或「上下分區」。上下分區模式下，以「功課＋提醒」及「時間分析」兩個頁籤切換。

如果想沿用已安裝插件的本機設定，請先備份舊資料夾，再以新檔案更新**原有插件資料夾**並在擴充功能頁重新載入。若把新版本作為另一個資料夾中的獨立插件載入，Chrome 可能視它為另一個擴充功能，選科、完成勾選及快取不會自動共用，需重新設定。

Chrome 的數字版本是 `1.8.1`，顯示版本名稱是 `BetterSMS_1.8.1`。

## Math Group 與選科

Math Group 和 M1／M2 合併為一個選單，不需要另選：

| Math Group | 延伸單元 |
| --- | --- |
| Gp1（CPC） | M1 |
| Gp2（SYT） | M2 |
| Gp3、Gp4、Gp5、Gp6 | 不修讀 M1／M2 |
| 全部組別（未設定） | 不隱藏任何 Math Group 或 M1／M2 |

從舊 Beta 更新時，以原來儲存的 Math Group 為準；舊版獨立的 M1／M2 設定不再生效，其他選科與完成勾選不因此清除。請更新後檢查自己的 Math Group。

功課及提醒各自套用同一套選科。X 組以提供的**科目＋老師代號對照表優先**：例如 FHM 的物理歸入 X3，即使內容寫 `X1` 也會按老師歸類，並向看到該項目的同學提示矛盾。M1／M2 標記與 CPC／SYT 老師矛盾時亦按老師分類並提示。若老師不在表內，才用 X 標記及科目輔助；科目與老師無法對上時會保留並提示核對。學校更換老師、派代課老師或一份功課適用多組時，請以 SMS 再核對。

中文、英文及 STEAM 一律顯示，無法辨識的其他科目會保留；未設定的 X 組不過濾。

## 時間分析（測試版）

- 在主畫面與功課、提醒並列；只分析目前**選科和日期篩選內、尚未勾選完成的功課**，不包括提醒。
- 以圓環圖呈現各科的已知預計時間；按 SMS 日期列出每日功課數量及已知總耗時，按日期可展開該日清單。選擇「全部已載入」可比較多天，選擇單日可看該日圖表。
- 分析內可選「今天」「明天」「下個上學天」「未來 7 天」「下星期」或指定日期；此日期與主畫面的功課／提醒篩選同步。
- 預計完成時間 = **瀏覽器目前時間 + 所選範圍內已知的功課預計分鐘**，假設從現在開始連續完成，**不包括休息、吃飯、交通或實際工作速度差異**。即使選擇未來日期，也不是自動安排從該日開始；此數值只供參考。停留在分析時，時間每分鐘更新。
- 讀不到時間的項目會列出及提示，日總數和整體估算只包含已知時間，**不是完整估算**；無法計算時顯示 `--:--`。SMS 寫明的 `0 分鐘` 依原值計算並提示，可能不代表實際不需時間。
- 同步失敗會標示上次成功的快取；未有成功資料時不會誤報「沒有功課」。若所選較早日期未在快取範圍內，亦會明確提示。
- 分析在本機計算，沒有使用第三方圖表服務，不會修改 SMS 內容。

## 日期與同步

「日期篩選」預設摺疊；「明天」是下一個曆日。未來 7 天包括今天；下星期是下一個星期一至星期日。**下個上學天只跳過週末，不會排除公眾或學校假期。**

SMS 預設從今天起載入；右下角設定可改載入起始日期，「全部已載入」只涵蓋已載入範圍。選擇比起始日期更早的日子時會自動往前重新抓取；若同步失敗，請檢查 SMS 登入及快取範圍。

每次開啟彈出視窗會嘗試讀取 SMS；亦可按「重新整理」。插件使用 Chrome 已登入的工作階段，不要求輸入或保存 SMS 密碼。若直接讀取被 Cookie 政策阻擋，會嘗試透過已開啟的 SMS 學生分頁讀取；登入過期時請重新登入。關閉彈出視窗時不會持續在背景同步。開發者模式位於右下角設定內。

## 私隱與開發測試

解析後的功課、提醒、完成狀態及設定保存在此瀏覽器的 `chrome.storage.local`。真實 `SMS.html` 可能包含帳戶和工作階段資訊，**不在發行包內**；測試資料均為虛構。此版本不包含具名學生預設，請自行選擇科目。

插件本身不需要 npm 套件。開發測試需 Node.js 及 npm：

```sh
npm ci
npm test
npm run check
```

測試涵蓋 Math 與舊設定遷移、X 組老師優先、功課／提醒分離、按日期合計、日期同步、完成勾選、未知時間、圓環圖及頁籤互動。
