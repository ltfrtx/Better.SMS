# Better.SMS v1.7.0-beta-alpha

> 下載 Release 的 Source code (zip) 解壓後，選擇包含 `manifest.json` 的資料夾以載入擴充功能。此發行版本不包含具名學生預設。


這是 **測試版**：包含正式版 1.6.2 的 X 組老師優先篩選，以及新的功課時間分析。原有藍灰介面、功課／提醒、日期、選科、完成勾選和開發者模式仍然保留。

## 安裝 Beta

1. 解壓 `BetterSMS_V1.7.0_beta_alpha.zip`，在 Chrome 開啟 `chrome://extensions`。
2. 開啟「開發人員模式」，選擇「載入未封裝項目」。
3. 選擇解壓後的 **BetterSMS_Beta** 資料夾（內含 `manifest.json`）。
4. 登入 [SMS 功課頁](https://sms.twghlkss.edu.hk/student/records.php?feature=homework)，安裝後重新載入該頁。點擊 Better.SMS Beta 圖示，展開「學生設定」選擇自己的 Math Group、X1、X2、X3 和 M1／M2。
5. 按右下角 **⚙ 設定 → 功課時間分析（測試版）**。

建議在獨立資料夾安裝 Beta，方便同時保留正式版。Chrome 會把不同資料夾視為不同擴充功能，**Beta 的選科、同步快取與完成勾選不會自動從正式版帶入**，需重新選擇。兩者各自儲存在本機。

Chrome 要求 `manifest.json` 的 `version` 使用數字，因此內部數字版本為 `1.7.0`，顯示名稱則為 `V1.7.0_beta_alpha`。

## 功課時間分析（測試版）

- 圓環圖按科目顯示 SMS 提供的預計時間比例；下方列出每份符合條件的功課、日期及時間。
- **只計算目前選科和日期篩選下、尚未勾選完成的功課**；不包括提醒。更改篩選或完成狀態後，重新打開分析即會更新。
- 預計完成時間 = **瀏覽器目前時間 + 已知的功課預計分鐘**，假設由現在開始連續完成，**不包括休息、吃飯、交通或實際工作速度差異**。分析展開期間會每分鐘更新，僅供參考。
- 讀不到預計時間的項目會列在清單並提示，**不會當作完整估算**；無法計算時顯示 `--:--`。SMS 寫明的 `0 分鐘` 依原值計算並另行提示，可能不代表實際不需時間。
- 若同步失敗，分析會標示使用上次成功資料；未成功載入資料時不會誤報「沒有功課」。
- 數據在本機計算，沒有使用第三方圖表服務，不會修改 SMS 內容。

## 篩選和日期

X 組以提供的**科目＋老師代號對照表優先**。例如 FHM 的物理歸入 X3，即使內容寫 `X1` 也會按老師歸類，並向看到該項目的同學提示矛盾。若老師不在表內，才用 X 標記及科目輔助；科目與老師無法對上時會保留並提示核對。若學校更換老師、派代課老師或一份功課適用多組，請以 SMS 再核對。

中文、英文及 STEAM 一律顯示，無法辨識的其他科目會保留。未設定的 X 組預設顯示全部，M1／M2 可設為未設定、不修讀、M1、M2 或兩者。

「日期篩選」預設摺疊，快捷選項包括全部已載入、今天、下個上學天、未來 7 天及下星期，也可指定單日。未來 7 天包括今天；下星期是下一個星期一至星期日。**下個上學天只跳過週末，不會自動排除公眾或學校假期。**SMS 預設從今天起載入；右下角設定可改載入起始日期。

## 同步與私隱

每次開啟彈出視窗會嘗試讀取 SMS；亦可按「重新整理」。插件使用 Chrome 已登入的工作階段，不要求輸入或保存 SMS 密碼。若直接讀取被 Cookie 政策阻擋，會嘗試透過已開啟的 SMS 學生分頁讀取；登入過期時請重新登入。關閉彈出視窗時不會持續在背景同步。

解析後的功課、提醒、完成狀態及設定保存在此瀏覽器的 `chrome.storage.local`。真實 `SMS.html` 可能包含帳戶和工作階段資訊，**不在發行包內**；測試資料均為虛構。此版本不包含具名學生預設，請自行選擇科目。

## 開發及測試

插件本身不需要 npm 套件。開發測試需 Node.js 及 npm：

```sh
npm ci
npm test
npm run check
```

測試涵蓋 X 組老師優先、功課／提醒分離、日期、不同時間格式、未知時間、跨日估算、圓環圖及互動。
