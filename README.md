# Better.SMS v1.6.0

> 下載 Release 的 Source code (zip) 解壓後，選擇包含 `manifest.json` 的資料夾以載入擴充功能。此發行版本不包含具名學生預設。


Chrome／Chromium 擴充功能，從 [SMS 功課頁](https://sms.twghlkss.edu.hk/student/records.php?feature=homework)整理「功課」與「提醒」，按照個人選科及日期篩選。保留原有藍灰色介面、完成勾選及開發者診斷。

## 安裝

1. 解壓縮 `BetterSMS_v1.6.0.zip`。在 Chrome 開啟 `chrome://extensions`。
2. 開啟右上角「開發人員模式」，選擇「載入未封裝項目」。
3. 選擇解壓後的 **BetterSMS** 資料夾（內含 `manifest.json`）。
4. 開啟 [SMS 功課頁](https://sms.twghlkss.edu.hk/student/records.php?feature=homework)，登入學生帳戶，安裝後重新載入一次該頁。
5. 點擊工具列的 Better.SMS 圖示；展開「學生設定」，選擇 Math Group、X1、X2、X3 與 M1／M2。

每次開啟彈出視窗會嘗試更新；亦可按「重新整理」。若顯示登入或連線錯誤，請先確認 SMS 已登入、重新載入 SMS 學生頁面，再按「重新整理」。插件會優先直接讀取；若瀏覽器的 Cookie 政策阻擋，會嘗試透過已開啟的 SMS 學生分頁讀取。

### 已有舊版？

若舊版是以「載入未封裝項目」安裝，並希望沿用同一個擴充功能 ID，可先備份舊資料夾，**將新版檔案放入原來的資料夾**，然後在 `chrome://extensions` 按該擴充功能的「重新載入」，並重新載入 SMS 分頁。相同 ID 下會沿用原有選科和功課完成狀態。由於舊版將功課和提醒混在一起，新版不會把舊的混合快取當成已分類資料；請登入後同步一次。

如果以另一個資料夾重新載入，Chrome 通常會視為**另一個擴充功能**，不會自動帶入原來的設定與勾選。可自行停用或移除不再使用的舊版。

## 使用方式

- 「學生設定」支援自訂選科。每個 X 組及 Math Group 預設為「全部／未設定」，不會在未選擇時隱藏該組資料。
- M1／M2 可設為未設定、不修讀、M1、M2 或兩者；預設「未設定」會顯示兩者。
- 中文、英文及 STEAM 一律顯示。其他沒有列在提供表格內的科目會保留並提示核對，以免漏掉共同功課。
- 功課與提醒使用相同選科和日期篩選。右下角 **⚙ 設定**可切換「頁籤模式」與「上下分區」，設定會保存在此瀏覽器。
- 同步資料後，可在卡片上勾選完成。提醒的勾選與功課分開保存。
- 日期快捷選項包括全部已載入、今天、下個上學天、未來 7 天及下星期；也可指定單日。**未來 7 天包括今天**；「下星期」是下一個星期一至星期日。
- 「下個上學天」只跳過星期六及星期日，**不會自動排除公眾假期、學校假期或特別上課日**。
- SMS 本身按起始日期載入。預設從今天起；⚙ 設定中可改「SMS 載入起始日期」。若選擇比目前載入範圍更早的單日，插件會自動往前載入；「全部已載入」只包括畫面所顯示起始日期及之後的資料。

## 篩選時需要留意

程式根據提供的選科表、科目名稱、老師代號及內容中的 `X1`／`X2`／`X3`、`Gp1`–`Gp6`、`M1`／`M2` 等標記判斷。若資料含糊或互相矛盾，會盡量保留可能屬於你的項目並顯示「請核對 SMS」，而不是靜默隱藏；最終仍以學校 SMS 的內容為準。

例如 CPC 同時是 Gp1／M1 老師、SYT 同時是 Gp2／M2 老師。如果一筆數學記錄沒有明確標示組別，而選科顯示它可能屬於你的 M1／M2，會保留並提示核對。學校更換老師、科目名稱或表格格式後，相關設定可能需要更新。

## 資料及私隱

插件只連接 `https://sms.twghlkss.edu.hk`，使用 Chrome 已登入的 SMS 工作階段，不要求輸入或保存 SMS 密碼。為方便下次查看，解析後的功課、提醒、完成狀態及設定會儲存在本機 `chrome.storage.local`；最後一次同步失敗時會顯示先前成功資料及錯誤提示，不會把失敗誤當成空資料。請勿與他人共用已登入的瀏覽器帳戶。

附上的真實 `SMS.html` 僅用作結構測試；由於其可能包含帳戶資料和工作階段資訊，**沒有放入此發行包**。`tests/fixtures/` 只包含虛構的測試資料。開發者診斷只記錄表格結構、數量和錯誤，不包含功課或提醒內容。

## 開發及測試

插件本身不需要安裝 npm 套件。開發測試需 Node.js 及 npm：

```sh
npm ci
npm test
npm run check
```

測試涵蓋中英文表頭、功課／提醒分離、空表和失敗保護、所有選科老師、M1／M2、資料矛盾、日期、介面互動及登入失敗等情況。
