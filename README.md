# Better.SMS

Chrome／Chromium 擴充功能，從 SMS 學生頁面整理功課與提醒，並支援日期、數學組別及選修科目篩選。

**版本：** V1.3.1<br>
**支援頁面：** `https://sms.twghlkss.edu.hk/student/*`

## 功能

- **提醒與功課分開擷取及顯示**：在彈出視窗切換「功課」與「提醒」分頁；提醒卡片顯示日期、科目和內容。兩種資料分別保存，不會把提醒併入功課清單。
- **安全處理舊資料**：舊版共用清單沒有足夠資訊可可靠地分離提醒與功課；升級後會等 SMS 各自頁面重新同步，再顯示相應清單，避免舊提醒繼續混進功課。
- **多語言表格解析**：支援中英文表頭及不同欄位順序，包含 DATE、SUBJECT、DETAILS 等提醒欄位。
- **選修科目篩選**：依 X1／X2／X3 設定、科目名稱及教師資訊篩選。即使 Chemistry 等科目沒有 X2 前綴，也會依使用者實際選科判斷。
- **同步狀態與診斷**：成功寫入擴充功能儲存空間後才標記同步完成；有需要時可啟用 Popup 開發者模式，手動重新抓取或複製診斷資料。診斷不包含功課或提醒內容。
- **品牌彩蛋**：正式名稱為 **Better.SMS**。在彈出視窗連續點擊標題五次，可切換顯示隱藏的「Fuck.SMS」；再點五次即可切回。

## 安裝（載入未封裝擴充功能）

1. 在 Chrome 開啟 `chrome://extensions`，開啟右上角的「開發人員模式」。
2. 選擇「載入未封裝項目」，選取本專案資料夾。
3. 重新載入 SMS 學生頁面，分別開啟功課及提醒頁，讓兩類資料各自完成首次同步，再點擊工具列上的 Better.SMS 圖示。

彈出視窗內的「開發者模式」是抓取診斷工具；它與 Chrome `chrome://extensions` 的「開發人員模式」是不同設定。

## 開發者模式

在 Better.SMS 彈出視窗展開「🛠 開發者模式」並勾選啟用，即可查看最近一次抓取的語言、表格／列數、辨識欄位與錯誤訊息；也可要求目前 SMS 分頁重新抓取，或複製診斷資料。若手動抓取時顯示找不到程式，請重新載入 SMS 頁面再試。

## 測試

```sh
npm test
npm run check
```

測試包含中英文表頭、提醒頁分類與分流、日期格式、空表、選修科目篩選，以及不帶 X 前綴的 Chemistry 判斷。舊版封存檔僅供參考；最新程式碼請以本資料夾為準。
