# Better.SMS v1.3

## 📌 版本介紹

改進功課同步方式，讓你更容易檢查同步狀態。

## ✨ 版本改變

- **手動同步：** 可在 SMS 頁面按「立即同步」，重新讀取功課。
- **同步狀態：** 顯示未同步、已同步、資料可能過期或同步失敗等狀態。
- **功課整理：** 合併頁面中擷取的資料，並減少重複項目。

請自行選擇適用的科目和組別。

## 📥 如何安裝

1. 在下方 **Assets** 下載並解壓 **Source code (zip)**。
2. 在 Chrome 或 Chromium 開啟 `chrome://extensions`，啟用 **開發人員模式**。
3. 點擊 **載入未封裝項目**，選擇解壓後包含 `manifest.json` 的資料夾。
4. 登入並重新載入 SMS 學生頁面，再點擊擴充功能圖示。

## ⚠️ 注意事項

此為歷史版本，如同步失敗，請先重新載入 SMS 頁面。
