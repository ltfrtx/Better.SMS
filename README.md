# Better.SMS v1.2

## 📌 版本介紹

功課整理加入日期篩選和選科設定，方便按照自己的需要查看功課。

## ✨ 版本改變

- **日期篩選：** 可查看全部、今天、下個上學天或未來七天的功課。
- **自訂選科：** 可自行設定 Math Group 及 X1、X2、X3 科目。
- **完成狀態：** 可勾選已完成的功課，方便追蹤進度。
- **介面：** 新增功課卡片及擴充功能圖示。

請自行選擇適用的科目和組別。

## 📥 如何安裝

1. 在下方 **Assets** 下載並解壓 **Source code (zip)**。
2. 在 Chrome 或 Chromium 開啟 `chrome://extensions`，啟用 **開發人員模式**。
3. 點擊 **載入未封裝項目**，選擇解壓後包含 `manifest.json` 的資料夾。
4. 登入並重新載入 SMS 學生頁面，再點擊擴充功能圖示。

## ⚠️ 注意事項

此版本的同步狀態可能顯示成功，但功課未必已同步；如資料不完整，請以 SMS 為準。
